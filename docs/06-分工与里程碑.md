## 2. 每个人做什么

### A · GUI

已有：HTTP 接口层（`api.py`，测试全绿）、`js/api.js`、最简联调页面。

1. 用自己的原型（`C:\E\projects\logisim\pair-programming-gui`）重做点单页：保留双栏布局和视觉风格，数据全部改为调用 `js/api.js`，删掉原型里的前端计价和 mock 服务。
2. 点单页状态机：编辑 → 下单中 → 待付款（倒计时）→ 制作中（进度）→ 完成 / 失败 / 取消 / 超时；对照 05 号文档 §5 第 1–14 项。
3. 重做维护页：库存表、补货、异常订单与退款、机器状态、销售概况（可加图表）。
4. 可选：引入单文件 Vue（下载到 `static/vendor/`，不要用 CDN）；支付宝模式下画二维码。
5. 负责 05 号文档 §5 的手工验收，组织全组点一遍。

可以自由发挥：页面结构、视觉、交互细节、是否用 Vue。边界：只调 `js/api.js`，不在前端写价格、库存、状态流转规则。

### B · 销售端 + 食材端

1. `IngredientServiceImpl`：先 `validate`、`quote`、`consumption_of`，再 `get_menu`，最后 `recommend`。
2. `OrderServiceImpl`：`create_order` → `get_order`（状态推进是核心，对照 03 号文档 §4.2 的表）→ `cancel_order` → `refund_order` → `list_orders`。
3. 加分：`AlipaySandboxPayment`（支付宝开放平台申请沙箱，见 `payment_alipay.py` 顶部说明）。

可以自由发挥：内部结构（拆小函数、状态表驱动……）、订单号格式、错误提示文案。边界：通过 Repository 存取，不写 SQL；通过 InventoryService 扣库存，不直接改库存表。

### C · 数据维护 + 机器维护

1. `InventoryServiceImpl`：最直接，建议先做，熟悉 Repository 用法。
2. `MachineSimulator`：先满足契约（按时间推进、故障），再加真实感（分步骤、热饮加热、杯子耗尽）。
3. `StatsServiceImpl`：按小时分布注意用北京时间；热门组合注意加料排序和并列规则。
4. 加分：更多分析指标，和 A 商量在维护页怎么展示。

可以自由发挥：模拟器的步骤和时长、统计的计算方式。边界：统计只读订单，不改；库存只通过 Repository。

### D · 数据结构

1. 和全组过一遍 `entities.py`、`enums.py`、`errors.py`，有异议第一周内改完，之后冻结。
2. `SqliteRepository`：建表（`schema.sql`）、初始化、各方法；嵌套字段 JSON 化后读回要还原成 tuple 和枚举。注意 Flask 多线程，写操作加锁。
3. 维护 `wiring.py` 和集成测试；最终保证 `python run.py --real all` 能完整演示。
4. 加分：订单导出 CSV、数据库备份。

可以自由发挥：表结构细节、索引、是否拆表。边界：Repository 的方法签名和行为。

## 3. 依赖与并行

```
第 1 周   D 冻结数据结构 ──┐
          全组确认接口 ────┼──► 之后所有人并行
                           │
          A 用参考实现做界面     （不依赖任何人）
          B 用参考库存/机器      （不依赖 C、D）
          C 用参考仓储           （不依赖 D）
```

因为有参考实现，**没有人需要等别人写完**。每个人随时可以 `python run.py --real <自己的组件>` 在完整程序里看效果。

## 5. 协作规则

- **分支**：每人一个分支（`feat/gui`、`feat/sales`、`feat/maintenance`、`feat/model`），合并到 `main` 前跑一遍 `pytest`。
- **提交前**：`pytest -k reference` 必须全绿（保证没把别人的测试改坏）。
- **AI 代码**：可以用 AI 写实现，但提交前自己读一遍，能讲清楚每段在干什么（课程要求）。参考实现也是 AI 写的，同样适用。
- **改接口**：走 04 号文档 §4 的流程，不要在自己分支里悄悄改。
- **数据库文件**：`data/` 已在 `.gitignore` 里，不要提交。
